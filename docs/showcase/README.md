# Полевой архив: исходники экспонатов

[Вернуться к выставке](../../README.md) · [Скачать автономную лабораторию](../assets/showcase/guardian-lab.zip?raw=true)

Лаборатория — один HTML-файл. В ZIP находится `index.html`: распакуйте и откройте его в браузере. У сайта нет сервера, запросов к API и внешних шрифтов. Установки или подключения к модели не требуется. HTML для браузера собран из [`src/`](src/), снимков детектора и одной локальной иллюстрации.

## Что в снимках

| Экспонат | Источник |
| --- | --- |
| Разбор хода | Две [фикстуры README](../../tests/fixtures/portfolio_demo.jsonl) и вариант с другим идентификатором. Метки и коды сигналов получены через `Detector(..., backend_name="heuristic")`. |
| Рентген | Синтетический журнал 14 ответов инструментов, сгенерированный в `pack_scene()`. Четыре представления получены из `build_evidence()`. Статус кадра вычисляется по содержимому итогового текста, а не по внутреннему списку отбора. |
| Контрольная пластина | Только агрегаты `valid.parquet`: матрицы и метрики трёх режимов правил. Исходных строк соревнования в HTML и CSV нет. См. [ограничения измерения](../../reports/README.md). |

## Пересобрать

Из корня репозитория, с Python 3.10+:

```bash
python -m pip install .
python docs/showcase/build.py
python docs/showcase/build.py --check
```

Команда обновляет HTML, ZIP, CSV и SVG двух пластин. Для растровых обложек, кинопетли, навигационных марок и печатного листа дополнительно нужны Pillow и шрифты DejaVu Sans, Sans Mono и Serif (путь можно указать через `SHOWCASE_FONT_DIR`):

```bash
python -m pip install Pillow
python docs/showcase/build.py --art
```

[`comparator.jpg`](../assets/showcase/comparator.jpg) — сгенерированная иллюстрация воображаемого прибора, не фотография оборудования хакатона. Все числа в экспонатах берутся из снимков вычислений. Движение кинопетли не иллюстрирует длительность инференса: это условный сканер по двум сохранённым результатам. Первый кадр уже содержит обе метки; в README предусмотрен отдельный стоп-кадр для системной настройки уменьшенного движения.

## Просмотр в браузере

Из распакованного ZIP достаточно открыть `index.html`. Для разработки можно запустить из корня:

```bash
python -m http.server --directory docs/showcase 4173
```

Откройте `http://localhost:4173/`. Щёлкните по каждой из трёх кассет и сверьте результат, переместите ползунок бюджета и сравните пластины `hard` / `any` / `CPU`.
